# docs-assets

This branch only hosts the screenshots used by the README on `main`
(`screenshots/*.jpg`). It is intentionally separate from `main` so the application repository
stays free of binary files (Hugging Face Spaces rejects them). Do not merge it into `main`.

Screenshots were captured from the production build; the generated documentation shown in them
is real output from the live Space (`qwen2.5-coder:3b`, Quick mode).
